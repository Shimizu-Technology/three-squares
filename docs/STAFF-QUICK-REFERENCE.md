# Three Squares — Staff Quick Reference

**Print this and keep it at the counter.**

---

## 🔑 Logging In

→ Go to **threesquaresgrill.com** → Sign In (top right)

**Your role determines what you can see:**
- **Staff** → Orders + POS only
- **Manager** → Orders + POS + Menu editing
- **Admin** → Everything

---

## 📋 Order Workflow

```
New Order → Confirm → Prepare → Mark Ready → Complete
```

1. **New order arrives** — you'll hear a notification sound
2. **Open the order** → click **Confirm** (customer gets notified)
3. **Prepare the food**
4. **When ready** → click **Mark as Ready** (customer gets pickup notification)
5. **Customer picks up** → click **Complete**

---

## 💻 POS Mode (Counter Orders)

**How to take an in-person order:**

1. Admin Panel → **POS Mode** (top nav)
2. Browse menu → tap items to add to cart
3. Adjust quantities if needed
4. Choose payment:
   - **Cash** → enter amount → app calculates change
   - **Card** → "Card (Manual)" → run card on reader
5. **Confirm Order** → done!

---

## 🛑 If an Item Runs Out

Admin → Menu → find item → **Edit** → toggle **Active OFF** → Save

*(Hides it from the menu immediately. Turn it back on when restocked.)*

---

## ⚙️ Closing / Changing Hours

Admin → **Settings** → Store Hours → update → Save

---

## 📢 Posting an Announcement

Admin → **Settings** → Announcement Banner → type message → Save

*(Shows at the top of the site for all visitors. Leave blank to remove.)*

---

## ❌ Cancelling an Order

Admin → Orders → open order → **Cancel Order** → confirm

*(Customer is automatically refunded. Takes 3–5 business days.)*
