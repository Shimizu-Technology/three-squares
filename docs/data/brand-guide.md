# Three Squares Brand Guide
*Extracted from website, images, and social media — Feb 11, 2026*

## Brand Overview

**Three Squares** is a sub-brand of **B&G Pacific LLC**. The branding is casual, warm, and approachable — comfort food with a local Guam feel.

---

## Typography

### Logo/Headlines
- **Script/Brush Font** — handwritten, casual, approachable
- Similar to: Brusher, Alex Brush, Playlist Script
- Bold brush strokes with natural variation

### Body Text
- Clean sans-serif (Squarespace default)
- Modern, readable

---

## Visual Style

### Photography
- **Warm & moody** — not overly styled
- **Natural lighting** — authentic restaurant feel
- **Color temperature**: 3500-4500K (warm)
- **Mood**: Approachable, unpretentious, real food

### Design Elements
- Polaroid-style photo frames
- Scattered/collage layouts
- Gold confetti accents
- Torn paper textures
- Social media-friendly aesthetic

## Recommended App Theme

For the Three Squares ordering platform, suggest:

```css
:root {
  /* Primary */
  --primary: #4A7FB5;        /* Pacific Blue */
  --primary-dark: #1E3A5F;   /* Navy */
  
  /* Accent */
  --accent: #F5C518;         /* Golden Sun */
  --accent-warm: #D4A030;    /* Amber */
  
  /* Neutrals */
  --background: #FFFFFF;
  --surface: #F0EDE8;
  --text: #1A1A1A;
  --text-muted: #666666;
  
  /* Food-inspired warmth */
  --warm-brown: #8B5E3C;
  --fresh-green: #4A7C3F;
}
```

This palette combines the corporate B&G Pacific blue with warm, appetizing food tones.
